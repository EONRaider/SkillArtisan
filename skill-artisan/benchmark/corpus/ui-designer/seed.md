# Seed draft — ui-designer

Rough, blank-slate ask fed to every comparison arm's authoring workflow.

---

I have a folder of reference UI screenshots — apps whose look I want to match, not copy —
and a rough idea of the product I'm building. I want a skill that turns that into a real
design system document: color palette (primary/secondary/accent/functional), typography,
component styles, spacing, and dark mode if the references show it — extracted from
actually looking at the images, not guessed from the product description alone.

From there, if I don't already have a PRD, it should help me build a minimal one (elevator
pitch, problem, audience, must-have features) before jumping to UI prompts, so the design
system has something concrete to serve. If I *do* already have a PRD, skip that step
entirely rather than redoing work I've already done. The end output should be
implementation-ready — something I can actually hand to a UI-generation step, not just a
mood board description.
