# Seed draft — deep-research

Rough, blank-slate ask fed to every comparison arm's authoring workflow.

---

I want a skill for producing genuinely rigorous research reports — market analyses,
literature reviews, competitive landscapes, technical briefs — not the kind of thing that
reads confidently but turns out to have invented a URL or leaned on a single source for a
load-bearing claim. It should parallelize research across sub-tasks so the main thread
doesn't drown in raw search results, build a real citation registry rather than loose
inline links, and track how fresh each source is so a time-sensitive claim isn't backed
by a two-year-old page without saying so.

The part I care about most: before any report is called done, it needs a genuine
counter-review pass — actively trying to find at least a few real problems with its own
conclusions (single-source claims, unsupported assertions, stale sources on time-sensitive
points) rather than a pass that always comes back "looks good." And it should never invent
a URL or a number that isn't actually traceable back to something a subagent found — mark
it unverified instead of filling the gap with something plausible-sounding.

It should also right-size itself — a quick "what is X" doesn't need the same six-task deep
dive as a full competitive analysis.
